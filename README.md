NoAI recursively scans a project for HTML documents and replaces human-readable text with deterministic gibberish. Your headings stay headings. Your links keep working. Your value proposition becomes a matter for future archaeologists.

The landing page in [`docs/`](docs/index.html) is generated by the actual Python transformer. Its footer is readable because institutional credibility requires exceptions.

> This is satire with working software. NoAI is not an established defense against AI training. The output can still be scraped, copied, or trained on. It will also be harder for people—including screen-reader users—to understand.

## Begin your semantic independence

Requires Python 3.11 or newer. Runtime dependencies: **zero**.

From a downloaded source checkout:

```sh
python evacuate.py /path/to/website --output /path/to/website-evacuated --dry-run
python evacuate.py /path/to/website --output /path/to/website-evacuated
```

Or install the package in a virtual environment:

```sh
python -m venv .venv
. .venv/bin/activate
python -m pip install .
noai /path/to/website --output /path/to/website-evacuated
```

On Windows, activate with `.venv\Scripts\activate`.

The output directory must be new, its parent must exist, and it must be outside the input project. Source files are never edited. The entire eligible project is copied so local assets remain available. Invalid UTF-8 HTML or an unreadable file aborts the operation and removes the temporary copy.

```sh
noai ./website -o ./website-protected --seed "the-arts-must-survive"
noai ./website -o ./website-protected --exclude private --exclude drafts
```

`--seed` sets the **Artistic Sovereignty Constant**. Equal inputs and seeds produce equal output. The program does not use Python's randomized `hash()`.

## What survives the transition

| Content | Treatment |
| --- | --- |
| Text in `.html` and `.htm` files, case insensitive | Garbled recursively |
| Page titles, `alt`, `title`, `placeholder`, `aria-label`, `aria-description` | Garbled |
| Common description, author, keyword, Open Graph and Twitter text metadata | Garbled |
| HTML tags, nesting, attribute order, quotes, indentation, newlines | Retained in the source |
| `href`, `src`, IDs, classes, event handlers, form names and other machine attributes | Retained |
| `script`, `style`, `pre`, `code`, `kbd`, `samp`, `svg`, `math` subtrees | Retained |
| Comments, declarations and basic template expressions | Retained |
| `data-noai` elements and their descendants | Retained, including text attributes |
| Non-HTML assets | Copied unchanged |
| Symlinks | Skipped, never followed |
| `.git`, `.venv`, `venv`, `node_modules`, `__pycache__`, `.pytest_cache` directories | Excluded |

For example:

```html
<section class="hero">
  <h1>Protect your voice.</h1>
  <a href="/manifesto">Read the manifesto</a>
  <code>print("Still completely legible")</code>
  <span data-noai>An exception of great institutional importance.</span>
</section>
```

The heading and link label change. The destination, code sample, and exempt span survive verbatim.

### Scope, with regrettable clarity

This is a source transformer for **UTF-8 HTML**, not a browser or a template compiler. It preserves the markup it receives; it does not repair malformed HTML or implement browser implicit-close rules. Use valid, explicitly nested markup around protected code and exempt elements.

Basic `{{ … }}`, `{% … %}`, `{# … #}` and `<% … %>` expressions are masked before parsing and retained. Nested delimiters, template raw blocks, JSX, PHP and arbitrary template languages are outside the contract. For framework projects, run NoAI on the rendered static HTML export and review the result.

Text generated by JavaScript, CSS, images, external content, form `value` attributes and other machine attributes is unchanged. Source code and comments may still contain readable prose. Garbled alt text reduces accessibility; it is included here to fulfill the joke, not to improve accessibility.

Whitespace and punctuation are preserved. ASCII letters retain their case shape; digits shift to other digits. Unicode letters and numbers become ASCII letters. Combining marks and emoji are retained. Entities that encode letters or digits are transformed; punctuation entities such as `&amp;` stay intact. Encoded letters are processed separately rather than as part of an adjacent word. One-letter words and accidental real words can occur. Do not use this as encryption, anonymization, or a secret-removal tool.

## The Semantic Evacuation Transform

The mathematics are real. The significance is entirely our own.

For an ASCII letter $c_i$ at zero-based position $i$ in token $w$:

$$
\mathrm{SET}_{\kappa}(w)_i = \alpha^{-1}\left(\left[\alpha(c_i)+1+\left(H(\kappa,w,i)\bmod25\right)\right]\bmod26\right)
$$

- $\alpha$ maps letters to integers from 0 to 25; original case is restored.
- $\kappa$ is the Artistic Sovereignty Constant; default: `sovereignty`.
- $H$ is SHA-256 interpreted as a big-endian unsigned integer.
- Its exact preimage is `b"noai-set-v1\0" + seed_utf8 + b"\0" + lowercase_token_utf8 + b"\0" + ascii_decimal_index`.
- A token is a maximal Unicode alphanumeric sequence, excluding underscores, as recognized by Python's `[^\W_]+` regex.

ASCII digits use the same construction with moduli 9 and 10, respectively. Other Unicode letters and numbers use `H mod 26` to select an ASCII letter, capitalized when the input character is uppercase.

Because an ASCII letter shifts by between 1 and 25 positions, it cannot remain unchanged. This supports our flagship metric:

$$
\text{ASCII Letter Displacement Rate} = 100\%
$$

This measures changed letters in eligible text. It does not measure semantic entropy, unreadability, privacy, or resistance to training. Protected regions are excluded. A scientific-looking equation is not evidence of a scientific breakthrough. We have therefore supplied several paragraphs.

## GitHub Pages

The generated website is committed in `docs/` and requires no build service, JavaScript, external fonts, or runtime dependencies.

1. Push this project to a GitHub repository.
2. In repository **Settings → Pages**, choose branch-based deployment and select your branch's **`/docs`** folder.
3. GitHub supplies the public URL after deployment.

Alternatively, preview locally:

```sh
python -m http.server 8000 --directory docs
```

Open `http://localhost:8000`. The navigation and FAQ disclosures work despite their unfortunate vocabulary.

To change the site, edit the readable originals in `examples/`, then regenerate:

```sh
python tools/build_demo.py
python tools/build_demo.py --check
```

Only the brand and footer are opted out. The absurd statistics also have their digits garbled. Their meaning was already questionable.

## Engineering standards, inexplicably

```sh
PYTHONPATH=src python -m unittest discover -s tests -v
python tools/build_demo.py --check
```

Tests cover deterministic output, character displacement, markup preservation, descriptive attributes, entities, template masking, protected subtrees, Unicode, asset copying, symlink exclusion, dry runs, failure cleanup, and CLI status codes. CI runs the suite and demo reproducibility check on Python 3.11–3.13.

The transformer collects source spans with Python's standard-library HTML parser and assembles replacements without serializing the DOM. Project output is staged in a temporary directory alongside its destination and renamed after successful processing. Avoid concurrent writers to the same output path or modifying the input during a run; this is a local publishing utility, not a filesystem transaction service.
